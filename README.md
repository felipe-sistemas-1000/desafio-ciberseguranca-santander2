# Conclusão:
Basicamenete tanto o Keylogger quanto Ransonwares são ferramentas poderosas, seja para se obter dados ou apenas danificar o sistema invadido,
porém o fator humano pode facilitar muito esses tipos de ameaça.

Para instalar um Keylogger, quem ataca pode utilizar Engenharia Social para fazer com que a
vítima instale o Keylogger em sua máquina, seja manualmente, através de e-mails, pendrive, etc.
Cabe lembrar também que o fato de um pequeno script ter a liberdade de rodar e enviar e-mais livremente pela rede demonstra um ambiente extremamente inseguro, pois 
jamais um processo desconhecido poderia rodar livremente no computador atacado, e muito menos passar pelo firewall livremente.

Para que se possa encriptar os arquivos em um ou mais computadores em uma rede, também é necessário um ponto inicial, e novamente
o fator humano conta muito, pois um usuário pode colocar um pendrive contaminado, executar programa que recebeu por e-mail, etc.
Outro detalhe é que esse tipo de ataque precisa encriptar arquivos em massa no computador atacado e pode também atacar outros na rede, e de forma nenhuma
isso poderia passar despercebido pelo antivírus.

Em resumo, para se mitigar esses tipo de ameaça, devem ser feitas pelo menos duas frentes de trabalho: 
1.Confirgurar o sistema (Antivírus, firewall, permissões limitadas para determinados usuários, utilização de máquinas virtuais, etc.);
2.Treinar usuários a respeito de ameaças e sempre reforçar comportamentos defensivos (não abrir programas desconhecidos, não acessar
sites duvidosos, etc.).
